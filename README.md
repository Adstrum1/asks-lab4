# Second Brain — Навчальні нотатки (PKM)

Автономний локальний вебінтерфейс для ведення навчальних нотаток за методологією **PARA** (Inbox, Projects, Areas, Resources, Archives) з підтримкою синтаксису **Markdown**, метаданих у форматі **YAML frontmatter** та двосторонніх вікі-зв'язків `[[Wiki-links]]`.

Проєкт працює **на 100% офлайн**: не потребує бекенд-сервера, сторонніх бібліотек чи CDN.

## 📝 Формат нотаток (YAML Frontmatter + Markdown)

Кожна нотатка зберігається у форматі Markdown із метаданими YAML frontmatter на початку файлу:

```markdown
---
title: "Назва навчальної нотатки"
created: "2026-11-10T13:00:00+02:00"
updated: "2026-11-10T13:00:00+02:00"
tags:
  - навчання
  - алгоритми
status: "Чернетка" # Варіанти: Чернетка | В процесі | Завершено | В архіві (або власний)
type: "Конспект"   # Варіанти: Конспект | Поняття | Література | Завдання | Резюме (або власний)
category: "Inbox"  # Категорії PARA: Inbox | Projects | Areas | Resources | Archives
---

# Назва навчальної нотатки

Текст нотатки у форматі Markdown.

Внутрішнє посилання на іншу тему: [[Оцінка складності алгоритмів O-нотація]].
```

### Поля метаданих:
- `title` (*рядок*): Заголовок навчальної нотатки.
- `created` (*ISO 8601*): Дата та час створення нотатки.
- `updated` (*ISO 8601*): Дата та час останнього редагування.
- `tags` (*масив рядків*): Список тегів для швидкої фільтрації (`#тег`).
- `status` (*рядок*): Поточний стан (`Чернетка`, `В процесі`, `Завершено`, `В архіві` або кастомний).
- `type` (*рядок*): Тип навчального матеріалу (`Конспект`, `Поняття`, `Література`, `Завдання`, `Резюме` або кастомний).
- `category` (*рядок*): Категорія методології **PARA**:
  - `Inbox` — первинні вхідні нотатки та швидкі ідеї;
  - `Projects` — поточні активні проєкти та дедлайни;
  - `Areas` — постійні сфери знань і навчальні дисципліни;
  - `Resources` — довідники, корисні посилання та шпаргалки;
  - `Archives` — завершені курси та архівні матеріали.

## 🔗 Зв'язки та Backlinks (`[[Назва нотатки]]`)

- Внутрішні посилання між нотатками створюються подвійними дужками: `[[Назва іншої нотатки]]`.
- При перегляді посилання стають клікабельними:
  - якщо цільова нотатка існує — відбувається миттєвий перехід до неї;
  - якщо нотатки ще не існує — система пропонує створити нову нотатку з цією назвою.
- У нижній частині кожної нотатки доступна інтерактивна панель:
  - **Вихідні посилання** (Outgoing links) — нотатки, на які посилається поточна.
  - **Зворотні посилання** (Backlinks) — усі інші нотатки, які мають посилання на поточну.

## 🚀 Спосіб локального запуску та перевірки

### Варіант 1: Пряме відкриття у браузері
Просто двічі клікніть або відкрийте файл `index.html` у будь-якому сучасному веббраузері (Chrome, Firefox, Safari, Edge).

### Варіант 2: Локальний HTTP-сервер
У корені каталогу виконайте команду:
```bash
python3 -m http.server 8000
```
Після чого відкрийте у браузері адресу [http://localhost:8000](http://localhost:8000).

## 🧪 Сценарій перевірки функціоналу

1. **Завантаження демонстраційних нотаток:**
   - При першому відкритті сторінки автоматично підвантажуються навчальні нотатки за всіма 5 категоріями PARA.
2. **Створення нової нотатки:**
   - Натисніть кнопку **"+ Нова нотатка"**.
   - Введіть назву, оберіть категорію PARA, статус, тип, додайте теги та Markdown-текст.
   - Скористайтеся live-preview та кнопками форматування.
   - Натисніть **"Зберегти"**.
3. **Перевірка зв'язків:**
   - Відкрийте нотатку `"Вступ до алгоритмів і структур даних"`.
   - У тексті або в блоці "Вихідні посилання" клікніть на `[[Оцінка складності алгоритмів O-нотація]]`.
   - Переконайтеся, що відбувся перехід, а в блоці "Зворотні посилання" відображається початкова нотатка.
4. **Пошук та фільтрація:**
   - У рядку пошуку введіть `alg` або `big-o` — список нотаток миттєво відфільтрується.
   - Клікніть на категорію `Areas` або на тег `#алгоритми` у сайдбарі.
5. **Експорт та імпорт:**
   - Натисніть **".md"** у верхньому тулбарі, щоб завантажити поточну нотатку як локальний `.md` файл з YAML frontmatter.
   - Натисніть **"Експорт JSON"** для резервного збереження всієї бази.
   - Спробуйте імпортувати файл через кнопку **"Імпорт"**.
